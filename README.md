# my-portfolio

Kayla's personal portfolio site — a single-page site styled after the **NYC subway** system
(MTA bullets, line tags, a subway-map skills section, and a "Mind the Gap" footer).

## Structure

- `index.html` — the whole site (markup + inlined CSS in a `<style>` block, so it's fully self-contained)

## Run locally

It's a single self-contained file — just double-click `index.html` to open it in a browser, or serve the folder:

```bash
python3 -m http.server 5173
# then open http://localhost:5173
```

## Sections

`ABOUT` (A line) · `SKILLS` (S line) · `PROJECTS` (P line) · `CONTACT` (C line)

Edit the copy, links (email / GitHub / LinkedIn / résumé), and the project card directly in `index.html`.
